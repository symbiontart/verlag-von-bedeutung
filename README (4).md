## Die Kernformel / The core formula

```
β* = D / (D + 1)     für β < 1
β* = D / (D − 1)     gespiegelt für β > 1
```

Der spektrale Exponent β beschreibt, wie sich Struktur über Skalen verteilt. Der Fixpunkt β\* markiert das Gleichgewicht zwischen Ordnung und Komplexität — ein Muster, das in Sprache, neuronalen Netzen, Ökosystemen und der Grossraumstruktur des Universums wiederkehrt.

*The spectral exponent β describes how structure distributes across scales. The fixed point β\* marks the balance between order and complexity — a pattern recurring in language, neural networks, ecosystems and the large-scale structure of the universe.*
