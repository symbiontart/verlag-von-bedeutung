# Verlag von Bedeutung

Website des Verlags von Bedeutung, Zürich: futuristische Sachbücher in Deutsch und Englisch.
Live: https://symbiontart.github.io/verlag-von-bedeutung/ (DE) · /en/ (EN)

## Aufbau
- `index.html` – deutsche Seite (eine Datei, Stil und Skript eingebettet)
- `en/index.html` – englische Seite, gespiegelt
- `img/` – Cover, Hero-Band, Favicon
- `og-image.jpg` – Vorschaubild beim Teilen
- `sitemap.xml`, `robots.txt`, `llms.txt` – Suchmaschinen und KI-Crawler
- `google5ab5872c0254be58.html` – Google-Search-Console-Verifizierung (nicht löschen)

## Pflege
Neue Bücher: Artikelblock `<article class="buch">` kopieren, Cover nach `img/`, Links im Block `bezug` eintragen, Seite in beiden Sprachen anpassen. `sitemap.xml` bei Änderungen mit neuem `lastmod` versehen.
